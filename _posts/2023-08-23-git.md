# 브랜치로 변경

git checkout <브랜치 이름>

# 새로운 브랜치를 생성하고 그 브랜치로 변경

git checkout -b <새로운 브랜치 이름>

google cloud platform에서 vm인스턴스를 만들고, vscode에서 ssh접속을 하여
git

아래 명령어를 입력하니 해결되었다.
git config --global --add safe.directory /var/www/2024-SolutionChallenge-MusicPalette

git config --global --list
git 설정 정보 보기

--local
현재 작업 중인 Git 프로젝트에만 해당되는 설정
.git/config 파일에 저장됨.

--global
사용자 디렉토리에 속하는 모든 git프로젝트에서 적용됨
~/.gitconfig 파일에 저장됨.
