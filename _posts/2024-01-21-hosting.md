## 호스팅 (Hosting)

> 웹 사이트나 애플리케이션의 파일과 데이터를 저장하고 공개하기 위한 서버 공간을 제공하는 서비스

목적: 웹 호스팅은 사용자가 웹 브라우저를 통해 웹 사이트에 접근할 수 있도록 웹 페이지를 저장하고 실행하는 과정을 담당합니다.

## 배포 (Deployment)

개념: 배포는 개발된 웹 애플리케이션 또는 웹 사이트를 실제 운영 환경으로 이동시키는 과정

목적: 개발자는 애플리케이션을 개발 환경에서 테스트하고, 그 후에 실제 사용자들이 이용할 수 있도록 운영 서버에 배포합니다. 배포는 보통 소프트웨어나 웹 애플리케이션을 최종 사용자에게 제공하기 위해 필요한 단계 중 하나입니다.
간단한 예로 설명하자면, 개발자는 로컬 컴퓨터에서 웹 애플리케이션을 개발하고 테스트합니다. 이후, 애플리케이션을 호스팅 서비스에 업로드하여 실제로 인터넷에서 접근 가능하게 합니다. 그리고 사용자가 쉽게 기억할 수 있는 도메인을 설정하여 도메인을 웹 호스팅 서버의 IP 주소에 연결합니다. 마지막으로, 애플리케이션을 사용자들이 이용할 수 있도록 배포합니다. 이러한 단계들은 각각 다른 역할을 수행하며, 웹 개발 프로세스의 중요한 부분을 형성합니다.
