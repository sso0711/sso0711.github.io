목표 : 웹 앱을 Docker 컨테이너 이미지에 패키징하고 GKE클러스터에서 이 이미지를 실행하여 부하 분산된 앱을 배포한다.
<br>
<br>
배포를 하나의 인스턴스의 리전에 한정할 경우, 다음과 같은 문제가 발생할 수 있었다.

- 여유 리소스 부족: 단일 환경, 특히 온프레미스 환경에서는 프로덕션 요구를 충족시킬 수 있는 컴퓨팅, 네트워킹, 스토리지 리소스가 모자랄 수 있습니다.
- 제한된 지리적 도달범위: 앱의 사용자가 전 세계 불특정 다수 어느 누구라도 사용할 수 있으므로, 지리적으로 멀리 떨어진 사용자들이 하나의 서버에 액세스해야 한다. 해당 위치에 도달하기 위해 전 세계를 돌아서 와야할 수도 있다.

##

1.Google cloud 프로젝트 선택 2.`Compute Engine API`
`Artifact Registry API`
`Kubernetes Engine API` 이 세 가지를 활성화해준다.
3.cloud shell 활성화
gcloud, docker, kubectl 명령줄 도구가 이미 설치되어있음 4.저장소 만들기 : Artifact Registry에 이미지를 저장하고 레지스트리에서 배포
4-1.컨테이너 이미지를 빌드하고 저장소에 푸시할 때 이 환경 변수를 사용
export PROJECT_ID=music-palette
4-2.ID값이 올바른지 확인
echo $PROJECT_ID
4-3.Google Cloud CLI의 프로젝트 ID를 설정
gcloud config set project $PROJECT_ID
4-4.music-palette-repo 저장소 만들기

```go
gcloud artifacts repositories create music-palette-repo \
   --repository-format=docker \
   --location=asia-northeast3 \
   --description="Docker repository"
```

REGION을 아래 명령어에서 확인 가능한 것 중 하나로 바꾸기
gcloud artifacts locations list

5.컨테이너 이미지 빌드
소스 코드, Dockerfile
5-1.music-palette-app 소스코드, dockerfile 다운로드

```
git clone [github저장소주소]
cd kubernetes-engine-samples/quickstarts/music-palette-app
```

5-2.docker이미지 빌드

```
docker build -t asia-northeast3-docker.pkg.dev/${PROJECT_ID}/music-palette-repo/music-palette-app:v1 .
```

현재 디렉터리에서 Dockerfile을 통해 이미지를 빌드하고, 해당 이미지를 PROJECT_ID에 해당하는 프로젝트의 repo저장소와 연결한다.

5-3. IAM 정책 바인딩을 추가한다.

```
gcloud artifacts repositories add-iam-policy-binding music-palette-repo \
    --location=asia-northeast3 \
    --member=serviceAccount:828528080001-compute@developer.gserviceaccount.com \
    --role="roles/artifactregistry.reader"
```

Region
project number

6. Artifact Registry에 docker 이미지 푸시
   GKE클러스터에서 이미지를 다운로드하고 실행할 수 있도록 이미지를 repo의 리전호스트인 artifact registry(REGION-docker.pkg.dev)로 푸시한다.

6-1.Artifact Registry에 인증
gcloud auth configure-docker REGION-docker.pkg.dev
6-2.docker 이미지 푸시
docker push REGION-docker.pkg.dev/${PROJECT_ID}/hello-repo/hello-app:v1

7. GKE 클러스터 만들기
   GKE 클러스터를 만들어 music-palette-app을 실행했다. GKE 클러스터는 GKE를 구동하는 오픈소스 클러스터 조정 시스템인 Kubernetes를 실행하는 Compute Engine VM 인스턴스의 풀로 구성된다.
