## C++ 함수를 이용한 정렬

1. 숫자 정렬

```c++
#include <algorithm>

int main(){
    int arr[8] = {12, 41...};
    std::sort(arr + 시작인덱스, arr + 끝인덱스 + 1);
}
```

배열을 오름차순 정렬

```c++
#include <algorithm>
#include <functional>

int main(){
    int arr[8] = {12, 41...};
    std::sort(arr + 시작인덱스, arr + 끝인덱스 + 1, greater<int>());
}
```

배열을 내림차순 정렬

> 문자열 배열도 동일하다.

## 정렬 알고리즘

- 문제 상황(데이터의 갯수, 범위, 정렬 정도)에 따라 적절한 정렬 알고리즘이 공식처럼 사용된다.
- 문제에서 정렬 함수를 구현하도록 요구하지 않는다면,
  일반적으로 최악의 경우에도 O(nlogn)을 보장하는 <b>표준 정렬 라이브러리</b>를 사용한다.

![Image](https://github.com/user-attachments/assets/0736f4d3-2799-4906-a503-05424eeb3361)

- 삽입정렬은 데이터가 거의 정렬되어 있을 경우 O(N)에 가깝다
- 퀵정렬은 최악의 경우 O(N^2)
  <br>

1. 선택정렬(selection sort)
   : 처리되지 않은 데이터 중 가장 작은 데이터를 선택해 (처리되지 않은 데이터들 중) 맨 앞의 데이터와 바꾸는 것을 반복
   - 시간복잡도 O(n^2)

```python
array = [7,5,9,0,3,1,6,2,4,8]

for i in range(len(array)) :
    min_index = i
    for j in range(i+1, len(array)):
        if array[min_index] > array[j]:
            min_index = j
    array[i], array[min_index] = array[min_index], array[i] # swap
```

<br>
<br>

2. 삽입 정렬(insertion sort)
   : 인덱스 0부터 i-1의 정렬된 배열에 i번째 요소의 적절한 위치를 찾아 insert하는 것을 반복
   선택 정렬에 비해 구현난이도 높지만 더 효율적.

```python
for i in range(1, len(array)):
    for j in range(i, 0, -1): # 인덱스 i부터 1까지 1씩 감소하며 반복하는 문법
        if array[j] < array[j - 1]: # 한 칸씩 왼쪽으로 이동
            array[j], array[j - 1] = array[j - 1], array[j]
        else: # 자기보다 작은 데이터를 만나면 그 위치에서 멈춤
            break
```

best :
worst : O(n^2)

3. 퀵 정렬(quick sort)
   : 피벗(기준)을 설정하고, 왼쪽에서부터 피벗보다 큰 데이터를 찾고, 오른쪽에서부터 피벗보다 작은 데이터를 찾아 서로 위치를 바꾸는 방법

- `분할정복(divide and conquer)` 알고리즘 중 하나 (불안정 정렬, 비교 정렬)
- 작은 데이터가 큰 데이터의 위치가 엇갈릴 때 피벗과 작은데이터의 위치를 서로 변경한다.
  - <사진>
  - 이 과정까지가 `분할(파티션)`이고, 피벗을 기준으로 왼쪽에 피벗보다 작은 데이터, 오른쪽에 큰 데이터로 나뉜다.
- 피벗의 좌,우 각각에 대해서도 퀵정렬을 재귀적으로 수행한다.

```python
def quick_sort(array):
    if len(array) <= 1 :
        return array
    pivot = array[0] # 피벗 (첫번째 원소)
    tail = array[1:] # 피벗을 제외한 리스트

    left_side = [x for x in tail if x <= pivot] # 분할된 왼쪽 부분
    right_side = [x for x in tail if x > tail] # 분할된 오른쪽 부분

    # 분할 이후
    # 왼쪽/오른쪽 부분 각각 정렬 수행
    return quick_sort(left_side) + [pivot] + quick_sort(right_side)
```

- 시간복잡도
  - 평균 O(NlogN)
  - 최악 O(N^2)

4. 계수 정렬 (counting sort)
   : 값에 해당하는 인덱스를 1씩 증가시켜, 해당 횟수만큼 순서대로 인덱스를 출력한다.

- 데이터가 0 이상의 정수이고, 수의 범위가 작게 제한되어 중복값이 많이 존재하는 배열을 정렬할 때 쓰인다.
- 데이터의 갯수 N, 최댓값 K일 때 시간복잡도 O(N+K)가 보장되어 매우 빠르다.

```python
count = [0] * (max(array)+1)

for i in range(len(array)):
    count[array[i]] += 1 # 값에 해당하는 인덱스 1씩 증가

# 정렬된 결과 출력하기
for i in range(len(count)):
    for j in range(count[i]):
        print(i, end=' ')

```

6. 힙정렬(heap sort)
   힙은 heappop시 우선순위 높은 것부터 꺼내므로 모든 원소를 힙에 넣었다가 꺼내면

`Minheap`

```python
import sys
import heapq
input = sys.stdin.readline

# 오름차순 힙정렬
def heapsort(iterable):
    h = []
    result = []
    # 모든 원소를 차례대로 힙에 삽입
    for value in iterable:
        heapq.heappush(h, value)
    # 힙에 삽입된 모든 원소를 차례대로 꺼내어 담기
    for i in range(len(h)):
        result.append(heapq.heappop(h))
    return result

res = heapsort(arr)

```

`Maxheap` -value로 부호를 바꾸어 넣고, -heap.heappop(h)로 부호를 바꾸어 꺼낸다.

```python
import sys
import heapq
input = sys.stdin.readline

# 내림차순 힙정렬
def heapsort(iterable):
    h = []
    result = []
    # 모든 원소를 차례대로 힙에 삽입
    for value in iterable:
        heapq.heappush(h, -value)
    # 힙에 삽입된 모든 원소를 차례대로 꺼내어 담기
    for i in range(len(h)):
        result.append(-heapq.heappop(h))
    return result

res = heapsort(arr)

for i in range(n):
    print(res[i])
```
