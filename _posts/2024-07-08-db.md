# 데이터베이스 시스템의 목적

파일 시스템을 통해 데이터를 관리할 경우, 파일마다 별도의 어플리케이션을 만들어 관리해야 한다. 이 경우 다음과 같은 문제점들이 생긴다.

- data redundancy / inconsistency
- ...

데이터베이스 시스템은 위의 모든 문제들을 해결해준다.

데이터베이스 시스템은 사용자들에게 추상적인 뷰를 제공해준다. 추상적이라는 의미는, 데이터가 어떻게 저장되고 유지되는지에 대한 세부사항을 숨긴다는 것이다.

- Data models 데이터와 그 관계, 일관성 제약을 설명한다.
- Data abstraction

## normalization theory

1.`functional dependencies`
`legal` DBMS는 실세계의 여러 제약사항들을 반영한 올바른
특정 attribute는 다른 attribute에 의해 제약사항이 생긴다.
ex)출생연도와 나이

`Dependency preservation`
functional dependencies 검사로 인한 오버헤드가 작아야 한다.
이 오버헤드가 작은 스키마가 좋은 스키마이다.
