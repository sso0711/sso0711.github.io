## WAS(Web Applicaiton Server)와 web server의 차이점

Web server : 클라이언트의 요청을 받아 `정적인 컨텐츠`를 반환하는 서버
ex)Apache, Nginx

WAS : DB조회나 로직 처리를 통해 `동적인 컨텐츠`를 반환하는 서버
ex)톰캣

정적 컨텐츠: 사용자나 요청 인자가 달라지더라도 바뀌지 않는 컨텐츠 (html,css,image)
<br>

동적 컨텐츠 : 사용자나 요청 인자에 따라 동적으로 생성하여 반환하는 컨텐츠

#### http 요청은 web server만 받을 수 있지만, 대부분의 WAS는 web server를 내장하고 있어 WAS도 http요청 받기가 가능하다.
