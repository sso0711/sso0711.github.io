## nginx

> web server / reverse proxy server 소프트웨어.

- 비동기 I/O기반 아키텍처로 (아파치보다) 메모리 사용이 효율적이다.
- 각 기능이 모듈화되어있고, 확장이 용이하다.

`reverse proxy` 부하 분산을 위해 클라이언트 요청을 여러 백엔드 서버로 전달하는 중간자적 역할을 수행한다. - 이를 통해 `로드밸런싱`을 적용할 수 있다.
`https`를 지원한다.
`SSL/TLS` 암호화를 통한 보안 연결을 제공한다.
`URL redirection` 트래픽 관리 및 검색 엔진 최적화

### 디렉터리 구조

`/etc/nginx/` 내에

`conf.d`

정적 컨텐츠를 가져오기 위한 웹 설정 폴더이다.
`sites-available` - default : 모든 설정 파일을 저장한다.
`sites-enabled` - default : sites-available디렉터리의 파일 중 실제 적용할 설정 파일의 symbolic link를 생성한다.

nginx는 sites-enabled 내 파일의 symbolic link를 통해 sites-available 내 설정 파일을 실행한다.
-> symbolic link의 변경만으로 서버 설정을 간편하게 바꿀 수 있다 !

#심볼릭 링크를 확인하기 위한 명령어
readlink /etc/nginx/sites-enabled/default

`nginx.conf` 기본 환경 설정 파일
